# Blood pressure targets in paediatric anaesthesia

Twelve questions on blood pressure targets for children under anaesthesia, put to six AI models (Claude, GPT, Gemini, Grok, DeepSeek, Llama) three times each on 19 September 2026 through OpenRouter. The answers are laid out as they came back, one page per question, on one scale, with the published reference under each card.

The page is a single file with the run built in. Answers are model output, not references; nothing here should be used for a patient.

Made by Dr Ganesh Sivasankara · MD · FRCA · FCARCSI · Consultant Anaesthetist.
